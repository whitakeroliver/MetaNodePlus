# MetaNodePlus

MetaNodePlus is a High-Performance, Real-Time distributed computing framework for scalable Node clusters.

MetaNodePlus is aimed at developers who need a straightforward, dependable solution.

## Installation

1. Clone the repository: `git clone https://github.com/harutosati/MetaNodePlus.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

To configure MetaNodePlus, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
